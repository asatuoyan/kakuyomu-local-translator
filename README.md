# 小说 EPUB 获取与本机翻译工具

支持 Kakuyomu（カクヨム）和小说家になろう（Syosetu）的原文获取，以及通过本机 Ollama 翻译 EPUB。下载、导入、翻译、术语管理和局部重译可在 GUI 或 CLI 中使用。

默认配置下，正文只在你的电脑、小说网站和本机 Ollama 之间流转。修改 `ollama_url` 为远程地址后，正文会发送至该地址。

## 安装与启动

需要 Windows 10/11、Python 3.11 和 Ollama。模型需要额外的磁盘空间和内存；翻译时建议关闭占用显存较多的软件。

1. 安装 Python 和 Ollama。
2. 在终端安装一个模型（默认使用 Q4_K_M）：

   ```powershell
   ollama pull hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M
   # 显存充足时也可选择：
   ollama pull hf.co/tencent/Hy-MT2-7B-GGUF:Q6_K
   ```

3. 双击 `run_gui.bat` 打开 GUI，或双击 `run.bat` 打开 CLI。

首次启动会创建 `.venv` 并安装依赖；以后仅在 `requirements.txt` 或解释器文件变化时重新检查安装。普通启动不执行 pip，也不安装浏览器。需要手动重新检查依赖时运行 `run_gui.bat -Update` 或 `run.bat -Update`。

GUI 默认以简体中文显示。顶部“当前功能 ▾”菜单提供“获取小说”“翻译小说”“检查译文”三个入口；获取小说页可切换网络下载和本地导入，翻译页可进入术语管理。顶部“搜索功能… Ctrl+K”可快速跳转，选中作品后中间显示书名，右侧设置可调整模型、Ollama 地址和主题；运行日志可从底部状态栏展开。在支持的 Windows 版本上，窗口标题栏也会随主题切换。新建翻译任务默认勾选简体中文。已有 `config.json` 中的 `target_language` 设置仍用于 CLI 和相关项目流程，可按需自行修改。

网页模式默认使用已安装的 Microsoft Edge，也可选择 Chrome、自定义 Chromium 或 Playwright Chromium。仅首次选择尚未安装的 Playwright Chromium 时下载浏览器；只翻译本地 EPUB 不需要下载浏览器。

CLI 在模型缺失时可询问是否下载；GUI 请先用上述命令安装模型。

## 功能与使用流程

### 1. 网站 → 日文 EPUB

支持：

- `https://kakuyomu.jp/works/...`
- `https://ncode.syosetu.com/.../`
- `https://novel18.syosetu.com/.../`

CLI 选择菜单 1，或使用 GUI 下载页。输入作品网址，在程序打开的独立浏览器中完成登录，再读取目录并选择章节范围，例如 `21-40`（包含首尾）。

程序保存正文、章节目录、插图、作品简介和网页提供的官方封面。每章下载后写入 `source-cache.json`；中断后选择相同范围会跳过已缓存章节。缓存用于续传，不会自动重新请求所有已下载章节以检查网站更新。

Kakuyomu 目录从作品页内嵌的完整分卷数据读取，不依赖当前展开的卷。目录可列出不代表当前账号可以读取正文，实际访问范围以账号权限为准。

默认章节请求间隔约 9–12 秒，插图请求另有间隔。可通过 `request_delay_seconds` 增加等待时间；程序保留至少 8 秒的章节请求间隔。临时网络错误可退避重试；检测到网站访问封锁时停止下载。

### 2. 日文 EPUB → 多语言 EPUB

CLI 菜单 2 或 GUI 翻译页支持多选繁体中文、简体中文、英文、日文、韩文、法文、德文和西班牙文，各语言依序翻译并生成独立 EPUB。

- 每 10 章生成一个分册，约每 100 章更新全书 EPUB，全部完成后再次合并。
- 各语言的项目、缓存和术语表独立保存在 `output/<原文文件名>_翻譯/<语言代码>/`。匹配原文和语言的旧中文项目继续使用原目录。
- 已完成章节可以续传；切换模型不会自动重译已经完成的章节。
- 原 EPUB 仅追加章节，且已完成章节的 URL 与正文逐章匹配时，可在原项目继续翻译；已有章节被修改、删除或重排时会停止并提示核对。
- 中文标题、简介和正文通过 OpenCC 统一简繁，此选项不改变 GUI 界面语言。
- GUI 中某种语言失败后会继续处理其他语言，并汇总成功结果和错误；点击“中止”会停止剩余任务。

EPUB 导入支持段落、普通容器、列表、引用、子标题、换行、图文混排和纯图片章节。插图按 XHTML 相对路径解析，保留不同目录的同名图片；找不到引用的图片时报告错误。翻译输出会重新排版，不保证保留输入 EPUB 的全部 CSS、字体或交互内容。

### 3. 追加到已有中文 EPUB

CLI 菜单 3 中先选择日文 EPUB，再选择中文母版。母版不会被覆盖，其原有内容和资源保留，新译章节追加到目录及阅读顺序末尾。程序自动检测母版主要使用简体还是繁体。

请选择仅包含尚未收录章节的日文 EPUB；程序不会推测它与母版章节的对应关系。

### 4. 手动网页单章续接

CLI 菜单 4–5 适合临时翻译一章或续接旧项目。在浏览器打开章节后回到命令窗口按 Enter；输入 `m` 切换模型，输入 `q` 安全结束。每累计 10 章重建一次 EPUB，退出时补写未打包结果。

### 5. TXT / Markdown / UMD / JAR 导入

CLI 菜单 7 或 GUI 导入页支持单文件和文件夹批量导入：

- TXT、Markdown 根据第 X 章/话/回、Chapter、Markdown 标题等规则切分章节。
- 文件夹按自然顺序排列，支持阿拉伯数字、全角数字和中日文章节数字。
- UMD、Java ME JAR 可提取支持格式的书名、作者、目录、正文和封面。
- 自动识别常见编码，包括 UTF-8、UTF-16、CP932、GB18030 和 Big5。
- 自动判断简体中文、繁体中文或日文，支持 Markdown 本地图片。
- 可打包 EPUB，或将已有中文内容导入可编辑项目。中文导入项目没有日文原文时，术语检查只能基于实际保存的文本进行，不能评估日文翻译准确性。

CLI 菜单 8 可打开 GUI。

## 翻译模型、完整性与中止

提供两个模型：

| 选项 | Ollama 模型名 |
|---|---|
| Hy-MT2 7B Q4_K_M（默认） | `hf.co/tencent/Hy-MT2-7B-GGUF:Q4_K_M` |
| Hy-MT2 7B Q6_K | `hf.co/tencent/Hy-MT2-7B-GGUF:Q6_K` |

来源：[腾讯官方 GGUF 仓库](https://huggingface.co/tencent/Hy-MT2-7B-GGUF)。旧配置中的其他模型在加载时改用 Q4_K_M；旧翻译模式和校对设置不再生效，已有译文保留。

翻译使用简短指令和纯文本输出，不要求 JSON，也不进行二次校对。多段原文以空行分隔；返回段落数不匹配时拆分重试。术语表和前文仅在有内容时加入参考。

流式响应必须收到完成标记才视为成功。提前结束、无效响应或长度限制导致的不完整结果不会写入缓存。段落数量一致仍不能保证语义上没有漏译，重要内容应人工核对。

连接中断、超时和暂时性模型错误默认最多重试 5 次，等待 10、20、40、60、60 秒。已完成批次保留。配置项：

| 配置 | 用途 |
|---|---|
| `translation_chunk_chars` / `translation_chunk_paragraphs` | 每批字符数 / 段落数 |
| `context_chars` | 前文参考长度 |
| `translation_max_retries` | 最大重试次数，0 表示关闭 |
| `translation_retry_delay_seconds` | 第一次重试等待秒数 |
| `request_timeout_seconds` | 网络请求超时 |

GUI 的“中止”适用于整书翻译和局部重译，也可取消重试等待或正在等待模型响应的任务。已完成批次/章节保留，迟到的响应不会写入项目。底层网络读取可能要等到下一个响应或超时才释放；本地 Ollama 可能短暂继续处理已取消的请求。再次开始会创建独立的取消状态。

## 术语管理、稽核与局部重译

- 每个作品/语言目录可保存 `glossary.json`，同名条目优先于全局设置。
- 全局 `glossary` 用于中文；其他语言使用 `glossary_by_language`，例如 `{"en": {"竜": "dragon"}}`，或该语言项目的术语表。
- 支持快速候选词提取，以及使用本机模型扫描人物、地名、组织、技能、魔法、称号和特殊设定。
- 支持候选词审核，以及 CSV、Excel `.xlsx`、JSON 导入导出。JSON 可使用条目数组、分类对象或原文到译名的字典。
- 翻译期间可检查术语是否落实；项目稽核会列出对应章节和段落。
- GUI 稽核页也会提示空译文、与原文相同的译文，以及长度明显异常的段落。这些是人工核对线索，不代表程序已确认漏译或误译。

**修改术语后的推荐流程：**保存术语表 → 在“译文检查”页选择项目并开始检查 → 在问题详情中重译选中段落，或从“更多操作”输入指定术语、勾选“全部术语”并执行范围重译。问题的“已处理／已忽略”状态保存在项目的 `audit-status.json` 中。

局部重译仅调用模型处理命中的正文段落，保留其他段落和图片，并重建输出。整书翻译项目的全书和分册都会更新；追加项目保留母版。若中途取消，已完成章节已保存，再次执行局部重译可更新 EPUB。不需要手动删除缓存。

稽核和局部重译同时支持 `project.json` 与 `translation-project.json`。旧翻译项目若没有保存原文，会提示选择创建项目时的原始 EPUB；校验文件和章节内容匹配后补齐对应关系。无法恢复原文或段落不对齐时会报告错误，不会把未检查的内容显示为“通过”。

## 项目存储、升级与备份

| 文件或目录 | 内容 |
|---|---|
| `translation-project.json` | 新版翻译项目清单、来源、语言和进度 |
| `chapters/000001.json` 等 | 原文、译文、图片引用和章节信息，按章原子写入 |
| `translation-cache.sqlite3` | 按批次事务提交的翻译缓存 |
| `translation-project.legacy.json` | 旧版整份 JSON 项目迁移时保留的备份 |
| `project.json` | 原有追加/文本导入项目，继续兼容 |
| `source-cache.json` | 下载续传缓存 |
| `assets/`、`source-assets/` | 项目资源；请与项目一起保留 |

新缓存包含模型、语言、术语表、章节身份、原文内容、段落位置和相关翻译设置，避免跨章节复用语境不同的相同对白。旧 `translation-cache.json` 保留，但缺少语境信息，因此不用于新任务的缓存命中；已经保存在项目中的完成章节仍会跳过。仅存于旧缓存、尚未保存为完成章节的内容可能需要重新翻译。

旧翻译项目在写入时迁移为分章格式，保留旧文件备份。备份或移动项目时，请复制整个项目目录，不要只复制清单或 SQLite 文件。进行迁移或批量修改术语前，建议保留目录备份。

## 登录与隐私

每种浏览器使用程序专用的独立配置目录，例如 `browser-profile-msedge`；不会读取日常 Edge 主配置。登录跳转属于正常流程，请在程序窗口完成登录，CLI 中返回作品页后再按 Enter。

可选 `cookies.json` 接受 Playwright `storage_state` 或 Cookie 数组，并仅导入 Kakuyomu 域名条目。不要分享 Cookie、浏览器配置目录、私人输出或未清理的整个项目目录；这些运行文件已加入 `.gitignore`。

程序只能获取当前账号正常有权打开的章节，不绕过会员、付费或其他访问限制。

## 常见问题

- **网站提示“不正と思われるアクセス”**：停止下载，不要连续刷新；稍后先用普通浏览器确认恢复，再继续。已经下载的章节可从缓存续传。
- **目录不全或登录失效**：确认账号能打开作品，在程序浏览器重新登录并读取目录。
- **Ollama 无法连接**：运行 `ollama serve`，确认 `http://127.0.0.1:11434` 可访问。
- **模型加载失败**：确认安装了所选量化版本；显存不足可用 Q4_K_M。
- **旧项目无法稽核**：选择创建项目时的原始 EPUB；重新下载或重新打包的不同文件可能无法通过匹配校验。
- **EPUB 无法打开或图片缺失**：保留原始 EPUB、项目和错误日志，检查源文件中的图片资源引用。
- **启动依赖异常**：用 `run_gui.bat -Update` 或 `run.bat -Update` 重新检查依赖。

## 开发验证

在安装了依赖的项目虚拟环境中运行：

```powershell
.venv\Scripts\python.exe -m unittest discover -v
```

测试使用本地样本和模拟模型响应，不需要下载小说或调用真实 Ollama。覆盖流式完整性、取消、重试与续传、语境缓存、项目迁移、局部重译和 EPUB 图文解析。
