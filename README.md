# 小说（Kakuyomu / 小说家になろう）EPUB 获取与本机翻译工具

程序把“获取日文原文”和“翻译 EPUB”分开处理，但统一放在同一个启动菜单中。小说正文只在你的电脑、小说网站（Kakuyomu / Syosetu）与本机 Ollama 之间流转。

## 功能

1. **Kakuyomu / 小说家になろう → 日文 EPUB**
   - 支持 Kakuyomu（kakuyomu.jp）与 小说家になろう / Syosetu（ncode.syosetu.com / novel18.syosetu.com）。
   - 使用你在独立 Chromium 窗口中的正常登录状态。
   - 读取作品目录后，按编号选择起止章节批量获取。
   - 保存日文正文、目录、正文插图、作品简介与网页提供的官方封面。
   - 每章保存下载缓存；中断后使用相同范围可继续。
2. **日文 EPUB → 独立中文 EPUB**
   - 可选择简体或繁体。
   - 每十章生成一个独立 EPUB 分册；约每百章合并更新全书 EPUB，全部翻译完成后再次合并。
   - 已完成章节逐章保存于 `translation-project.json`；中断后选择同一原文与目标语言即可接续。
3. **日文 EPUB → 追加到已有中文 EPUB**
   - 原中文 EPUB 作为母版，不会被覆盖。
   - 完整保留母版原有排版、图片、字体、CSS、封面、元数据和目录。
   - 新译章节与插图追加到目录及阅读顺序末尾。
4. **TXT / Markdown / UMD / JAR 電子書與資料夾批次導入（支援中文小說與日文原文）**
   - 支援單一全本 `.txt` / `.md` / `.umd` / `.jar` 檔案，透過智能正則（第X話/章/回/Chapter/Markdown `#` 等）自動切分章節與段落。
   - **智慧自然排序（支援中日文章節數字與全形數字）**：支援包含多個章節檔案的資料夾批次導入，自動將 `第一章`、`第二章`、`第十章`、`第十一章`、`第一百章` 或 `1.txt`, `2.txt`, `10.txt` 依真實數字順序精準排列。
   - **原生支援 UMD (.umd) 與 Java ME JAR (.jar) 電子書**：自動解鎖二進制 UMD 與 Java JAR 壓縮包，萃取書名、作者、章節目錄、內文與封面圖片。
   - **智能語系自動識別**：自動辨識繁體中文、簡體中文與日文原文。
   - **一鍵打包 EPUB**：依語言屬性一鍵輸出排版精美的標準中文或日文電子書。
   - **一鍵導入中文專案**：將已有中文小說直接轉為專案，免重新翻譯，立即可進行術語合規稽核、專有名詞修正與局部重譯。
   - 支援 Markdown 內嵌圖片標籤 `![alt](path)` 自動解析與 EPUB 插圖打包。
   - 支援自動編碼識別（UTF-8, UTF-8-sig, Shift-JIS/CP932, GBK/GB18030, Big5, UTF-16 等）。
5. 保留原有“手动打开 Kakuyomu / Syosetu 单章并续接”的模式。

## 翻译模式

- **快速**：`qwen3:8b`，较大分块。
- **质量**：`qwen3:14b`，较小分块和较长前文。
- **混合**：8B 初译后，14B 对照日文立即校对。初译记录保留，EPUB 显示校对版。
- **自定义**：填写其他 Ollama 模型名。

模型未安装时，程序会询问是否由 Ollama 自动下载。网页续接模式每累计十章重建一次 EPUB，退出时会补写尚未打包的结果。

## 安装和启动

需要 Windows 10/11、Python 3.11、Ollama，以及足够的模型存储空间。
- **圖形化使用者介面 (GUI)**：雙擊 `run_gui.bat` 或在主選單選擇「8. 開啟圖形化使用者介面 (GUI 簡易操作)」。
- **終端命令列介面 (CLI)**：雙擊 `run.bat`，可選擇「7. 批次導入 TXT / Markdown 檔案或資料夾」。

首次運行會自動創建虛擬環境、安裝依賴與 Chromium。

RTX 4060 Laptop 8 GB 可运行 `qwen3:14b`，但通常会有部分层放在系统内存，速度明显慢于 8B。建议翻译时关闭占用显存较多的软件。

## Kakuyomu 登录

默认方式最稳妥：

1. 选择菜单 1。
2. 程序打开独立 Chromium。
3. 你亲自在 Kakuyomu 页面登录。
4. 預設使用電腦已安裝的 Microsoft Edge，登入狀態保存在程式專用的 `browser-profile-msedge`，以後自動復用。它不會讀寫日常 Edge 主設定檔，因此平常的 Edge 不必關閉。

首次開啟作品時，Kakuyomu 可能自動跳轉到登入頁。這是正常流程：請在程式開啟的瀏覽器中完成登入，等畫面返回作品頁後，再到命令視窗按 Enter。程式已允許登入重新導向，不會再把該跳轉當作導覽錯誤。

程序不要求你提供账号密码。如果确实需要导入 Cookie，可在程序目录放置 `cookies.json`；它只接受 Playwright `storage_state` 或 Cookie 数组，并且只导入 Kakuyomu 域名的条目。不要分享 `browser-profile`、`cookies.json` 或整个未清理的程序目录。

只能获取当前账号正常有权打开的章节；程序不绕过会员、付费或其他访问限制。

## 菜单说明

### 1. 生成日文原文 EPUB

输入作品网址，例如：

```text
https://kakuyomu.jp/works/822139846748662387
或
https://ncode.syosetu.com/n2027ci/
```

登录确认后，程序列出可访问目录。输入 `21-40` 会获取第 21 至 40 章，首尾均包含。目錄只載入一次，並直接讀取頁面內嵌資料，不會快速展開或捲動各分卷。預設章間隔約 9–12 秒，插圖請求另有 1.5–3 秒間隔。可在 `config.json` 調高 `request_delay_seconds`，但程序會強制至少 8 秒，不能用設定降低這個安全下限。

啟動網頁相關模式時可選 Microsoft Edge、Google Chrome、Playwright Chromium 或自訂 Chromium 瀏覽器。每一種瀏覽器都使用獨立的程式專用設定檔；這比直接共用你日常使用中的主設定檔穩定，也避免設定檔鎖定或損壞。

目錄會從作品頁內嵌的完整分卷資料按原順序讀取，不依賴畫面當下展開的區塊。例如作品頁標示全 182 話時，程式應列出 182 話，而不是某個分卷的 39 話。目錄可列出不等於帳號必然能讀取正文；付費或限定內容仍以目前登入帳號的實際權限為準。

### 出现「不正と思われるアクセス」时

这是 Kakuyomu 的临时访问封锁。程序检测到该页面后会立即停止，不会连续重试。请关闭程序，不要反复刷新；关闭 VPN、代理或加速器，等待数小时后先用普通浏览器确认作品页可以正常打开，再运行程序。若普通浏览器仍显示相同页面，只能继续等待或联系 Kakuyomu。已有章节保存在 `source-cache.json`，恢复后重新选择同一范围会跳过缓存内容。

### 2. 翻译为独立中文 EPUB

选择日文 EPUB、中文用字和模型模式。翻译缓存保存在对应项目目录，可在中断后再次运行。

### 3. 追加到已有中文 EPUB

先选择日文 EPUB，再选择已有中文 EPUB。程序自动检测母版主要使用简体还是繁体；日文 EPUB 内的章节全部依次翻译并追加。请选择只包含“尚未收录章节”的日文 EPUB，程序不会猜测它与母版章节的对应关系。

### 4–5. 网页单章续接

适合临时翻译一章，或继续旧版程序建立的项目。在浏览器打开章节后回到命令窗口按 Enter；输入 `m` 切换模型，输入 `q` 安全结束。

## 目录与隐私

- `browser-profile/`：本机浏览器登录状态。
- `cookies.json`：可选 Cookie 导入文件。
- `output/<作品>/`：EPUB、项目记录、缓存和插图。
- `translation-cache.json`：初译缓存。
- `review-cache.json`：14B 校对缓存。
- `source-cache.json`：网页原文章节下载断点。

以上敏感或个人文件均已列入 `.gitignore`。

## 术语表与实体管理

程序提供全自动的術語表掃描、候選詞提取、多格式匯入匯出、作品獨立術語表與局部重譯功能：

### 1. 每部作品獨立 `glossary.json`
- 每個作品專案資料夾皆支援存放獨立的 `glossary.json`，自訂該部作品專屬的角色譯名與設定。
- 專案獨立術語優先權高於全域 `config.json`；若未設定則自動繼承全域術語表。

### 2. 候選術語自動提取與 AI 掃描
- **快速提取候選詞（秒級統計）**：運用啟發式特徵快速統計片假名、標點括號（【】、《》、『』）、稱號爵位、技能招式及地名，提供例句與頻次預覽。
- **AI 深度實體識別**：由本機 LLM 針對小說內文樣本深度識別 7 大分類（人物名、地名、組織、技能、魔法、稱號、特殊設定）並給出推薦譯名。
- **術語確認與審核**：提供互動式審核面板，可快速勾選、修改譯名並一鍵匯入。

### 3. 多格式匯入與匯出
- **CSV 表格**：自動識別表頭欄位（日文原文、中文譯名、類別、備註）或按順序讀取。
- **Excel 試算表（.xlsx）**：支援完整單一工作表或按 7 大分類分頁的工作表。
- **JSON 檔案**：支援標準條目陣列 `[{"source": "...", "target": "...", "category": "...", "note": "..."}]`、分類物件或簡易字典 `{"日文": "中文"}`。

### 4. 翻譯合規性檢查與按影響範圍局部重譯
- **即時合規檢查**：翻譯過程中（初譯與 14B 校對），系統自動比對日文原文出現的術語是否在中文譯文中得到一致落實。
- **歷史專案稽核**：一鍵掃描既有專案所有章節，精確定位未落實術語的章節與段落。
- **按術語影響範圍局部重譯**：當修改或新增特定術語時，系統自動分析包含該術語的章節與段落，僅對受影響章節進行局部重譯並即時更新 EPUB，**無須整本重翻**！

### 5. 章節 ID 與內容雜湊防重複機制
- 自動解析作品來源之章節專屬 ID（Kakuyomu episode ID / Syosetu part ID）與段落內容 SHA-256 雜湊值。
- 下載或續接時自動比對雜湊與快取，避免重複請求並精準偵測章節內容更新。

### 6. 指數退避與中斷恢復機制

- 翻譯及校對遇到連線中斷、逾時、暫時性 HTTP 錯誤或模型輸出異常時，自動重試失敗的批次，無須關閉彈窗或重新按開始；已完成的批次保留快取。
- 預設最多自動重試 5 次，依序等待 10、20、40、60、60 秒；重試訊息顯示於日誌，超過次數才回報失敗。可在 `config.json` 設定 `translation_max_retries`（設為 `0` 關閉）及 `translation_retry_delay_seconds`（首次等待秒數）。舊設定檔未加入這兩項也會套用預設值。
- GUI 的「中止」可取消等待中的翻譯重試；模型不存在、設定或檔案錯誤仍需修正後再執行。此機制不改變網站封鎖時停止下載的行為。
- 下載網路請求具備動態指數退避（Exponential Backoff）與抖動（Jitter）重試機制，提高對頻率限制與網路波動的容錯能力。
- 每章下載即時寫入快取，中斷後重新執行可無縫接續下載。

在 `config.json` 的 `glossary` 中填寫或由程式自動寫入固定譯名：

```json
"glossary": {
  "アイリス": "愛麗絲",
  "エクスプロージョン": "爆裂魔法"
}
```

修改术语表后，旧缓存不会自动重翻。需要重译时，请先备份项目目录，再删除相应缓存条目或建立新项目。

## 常见问题

- **目录章节不全**：先确认账号能在浏览器中打开这些章节，再重新读取目录。
- **登录失效**：关闭程序，重新选择菜单 1，在打开的 Chromium 中再次登录。
- **Ollama 无法连接**：运行 `ollama serve`，确认 `http://127.0.0.1:11434` 可用。
- **14B 很慢**：改用混合或快速模式；8 GB 显存下 14B 加载等待属于正常现象。
- **EPUB 无法打开**：保留项目目录并提供报错信息；可先用 Thorium Reader 或 Koodo Reader 验证。
